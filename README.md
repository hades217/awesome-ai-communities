## Choose a community format

- **Technical demos:** show working code and discuss implementation. See AI Tinkerers and Builders After Dark; the latter also covers non-AI projects.
- **Learning & building:** try tools or build with peers. See Build Club, Malaysian AI, AI After Hours and Vibe Coding Collective.
- **Networking & project exchange:** meet practitioners and share projects. See the listed AI Circle city chapters.
- **Applied AI:** broader education and discussion. See AI LA.

## Scope and evidence

This is a curated starter directory, not an exhaustive global database or a live event feed. Country guides include source links, review methods, dates and affiliation labels. Some official sites block scripted access; search-index evidence is labelled separately from a direct page read. We do not publish private chat invitations or contact lists.
